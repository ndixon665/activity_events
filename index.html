jQuery Selectors Used

#click-button
The ID selector selects the element with the ID "click-button." It is used here to add a click event to the button.
#double-click
The ID selector selects the paragraph with the ID "double-click." It is used here to add a double-click event.
#hover-message
The ID selector selects the paragraph with the ID "hover-message." It is used here to add a hover event.
